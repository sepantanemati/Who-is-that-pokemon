This project is made with flask, html and css.
The game works by showing you the picture of a pokemon and letting you guess the name
The game has 3 mode: chill, hard, impossible
Chill mode: In chill mode you get the image of the pokemon and guess the name and is mosltly for training
Hard mode: Hard mode is the same as chill mode but there is a point system and a record system, 
you start with 10 points and you lose a point per every wrong guess and gain a point for every right guess, but if you reach 0 points you lose and need to restart, 
the goal is to get a high record.
Impossible mode: Impossible mode is hard mode but you only get the shape of the pokemon but you gain 2 points per right guess.
